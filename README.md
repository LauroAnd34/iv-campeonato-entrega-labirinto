# Desafio de Entrega, Labirinto Inteligente e Carros Autônomos · sincronizados

Um serviço por prova (mesmo código, variável `MODALIDADE`):

| Variável | Valor |
|---|---|
| `MODALIDADE` | `entrega`, `labirinto` ou `carros` |
| `PIN` | senha de edição da coordenação (o telão não precisa) |

- Coordenação: `https://<serviço>.onrender.com/`
- Telão: `https://<serviço>.onrender.com/#telao`

Iniciar localmente: `MODALIDADE=entrega PIN=1234 PORT=8771 node server.js`
